# Code of Conduct

Be kind, be specific, assume good faith. Harassment, personal attacks and discrimination are not
tolerated in issues, pull requests or any other project space. Maintainers may remove, edit or
reject contributions that do not follow this, and may ban repeat offenders.

This is a condensed version of the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
which applies in full. Report problems to the address on [manydisplays.com](https://manydisplays.com).
